# حقوق‌یار

وب‌اپ فارسی محاسبه کارکرد و مزایای ماهانه.

- موظفی: (روزهای ماه - تعطیلات کاهنده) × ۶٫۵۱ - ۸
- حضور واقعی: E×۶ + N×۱۲ + M×۶
- اضافه‌کاری: max(۰، حضور - موظفی) + H×۶
- اضافه‌کاری ساعتی: ۲۱۹٬۰۰۰ تومان
- حق شب: هر نوبت N برابر ۹۰۰٬۰۰۰ تومان
- تعطیل‌کاری: نصف ساعات واقعی × ۱۵۰٬۰۰۰ تومان
- مزایا از حضور و اضافه‌کاری مستقل‌اند.

اطلاعات بایگانی در حافظه مرورگر همین دستگاه ذخیره می‌شود. پاک شدن داده‌های مرورگر ممکن است آن را حذف کند؛ گزارش‌ها را جداگانه نگهداری کنید. مالیات برآورد نمی‌شود.
