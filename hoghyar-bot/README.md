# ربات عمومی تلگرام حقوق‌یار

این پوشه بک‌اند ربات عمومی حقوق‌یار است. اپ GitHub Pages نباید توکن تلگرام یا اطلاعات خصوصی کاربران را نگه‌داری کند؛ این Worker پیام‌های تلگرام را دریافت می‌کند، داده‌ها را در Cloudflare D1 نگه می‌دارد و یادآوری‌ها را زمان‌بندی می‌کند.

## امکانات نسخه اولیه
- ثبت‌نام با /start
- راهنما با /help
- ثبت یا ویرایش شیفت با /set YYYY-MM-DD نوع HH:MM
- حذف شیفت با /delete YYYY-MM-DD
- مشاهده شیفت امروز و فردا با /today و /tomorrow
- تنظیم زمان یادآوری با /remind 60
- ارسال خودکار یادآوری با Cron هر ۵ دقیقه
- هر کاربر فقط شیفت‌های متعلق به شناسه تلگرام خودش را می‌خواند و تغییر می‌دهد.

## محدودیت فعلی
تاریخ ورودی در این نسخه میلادی و به شکل YYYY-MM-DD است. ساعت شروع شیفت را خود کاربر مشخص می‌کند. اتصال مستقیم فرم‌های اپ، تقویم شمسی و پنل مدیریت عمومی در مراحل بعدی اضافه می‌شوند.

## پیش‌نیاز راه‌اندازی
1. ساخت ربات از طریق @BotFather و دریافت Bot Token.
2. ساخت حساب Cloudflare.
3. ساخت پایگاه داده D1 با نام hoghyar-bot و اجرای schema.sql.
4. جایگزینی شناسه پایگاه داده در wrangler.toml.
5. افزودن Secrets با نام‌های BOT_TOKEN و TELEGRAM_WEBHOOK_SECRET.
6. استقرار Worker و ثبت Webhook تلگرام با URL اختصاصی Worker و همان secret.

هیچ توکن یا کلید محرمانه‌ای را در GitHub یا فایل‌های این مخزن قرار ندهید.

## دستورات نمونه
- /set 2026-11-20 شب 19:00
- /delete 2026-11-20
- /remind 60
- /today
- /tomorrow

برای استقرار با Wrangler:
1. فایل wrangler.toml.example را به wrangler.toml کپی کن.
2. یک D1 بساز و database_id را در تنظیمات قرار بده.
3. schema.sql را روی دیتابیس اجرا کن.
4. دو Secret را با wrangler secret put ثبت کن.
5. Worker را با wrangler deploy منتشر کن.
6. Webhook را با متد setWebhook تلگرام ثبت کن و secret_token را هم ارسال کن.

Webhook باید HTTPS و secret فعال داشته باشد. توکن را در پیام یا کد عمومی منتشر نکنید.
